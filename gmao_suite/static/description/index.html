GMAO Suite

Gestion de Maintenance Assistée par Ordinateur — native Odoo 13 Community

Cycle de maintenance complet : équipements, interventions correctives & préventives, rapports d'intervention structurés, analyse des pannes, attribution automatique d'équipe, contrats, pièces, conformité, efficacité énergétique, tableau de bord temps réel et rapports PDF décisionnels.

Odoo 13 CE · Python 3.7+ · Multilingue · 100% natif (zéro Enterprise)

Ce qui est implémenté

Patrimoine & interventions

✓ Sites multi-localisation (géolocalisation) & catégories d'équipement

✓ Équipements : coût cumulé, ratio coût/valeur, recommandation de remplacement

✓ Demandes correctives & préventives — workflow complet

✓ Génération automatique des demandes préventives (CRON)

Rapport d'intervention technicien

✓ Catalogue de codes panne / activité (ISO 14224 pragmatique)

✓ Symptôme, cause racine, travaux, recommandation, sévérité

✓ Phrases-types réutilisables (sélection + auto-remplissage + création à la volée)

✓ Rapport obligatoire avant clôture → données fiables

Aide à la décision

✓ Analyse de récurrence des pannes (code × équipement)

✓ Tableau de bord temps réel (Chart.js) : KPI, MTTR/MTBF, disponibilité

✓ Attribution automatique d'équipe par scoring multi-critères

Organisation & contrats

✓ Équipes & techniciens : charge, occupation, réussite, temps de réponse

✓ Couverture (sites) & compétences (catégories) par équipe

✓ Contrats : renouvellement, facturation, alertes d'expiration

✓ Pièces : stock natif, allocation, refacturation, kits de pièces

Rapports métier (écran + PDF)

✓ Dossier équipement, analyse remplacement, rapport site, analyse des pannes

✓ Bon d'intervention, rapport financier consolidé, conformité

✓ Page détail décisionnelle au clic + prévisualisation split-view des documents

✓ Mention du client (via contrat) / société sur les PDF

Conformité, énergie & transverse

✓ Inspections conformité & sécurité → génération de demande corrective

✓ Efficacité énergétique : graphique de consommation + plan d'actions traçable

✓ RBAC fin (8 domaines × 4 niveaux), multi-société, multilingue, emails

En bref

20 modèles Python · 18 vues XML · 10 rapports QWeb PDF · 13 templates email · 13 CRONs · 8 domaines RBAC · tableau de bord Chart.js · multi-société · multilingue · 0 dépendance Enterprise.
